## Ручной регрессионный чек-лист (Android / мобильный)

### 2.1. Вход на экран и вкладки

- [ ] Нижняя навигация → «Продажа»; заголовок «Продажа», подзаголовок корзины обновляется.
- [ ] Вкладка «Поиск» активна по умолчанию.
- [ ] Вкладка «Каталог» переключается без артефактов, дерево не пустое при наличии товаров.

### 2.2. Поиск товара

- [ ] Пустой/короткий поиск показывает состояние «Начните поиск...».
- [ ] Ввод 1 символа не ломает UI.
- [ ] Ввод >= 2 символов показывает карточки: вкус, бренд/формат, доступно N, цена.
- [ ] Товары с нулевым остатком не попадают в выдачу.
- [ ] Тап по карточке добавляет товар в корзину и очищает поле поиска.
- [ ] Повторный тап по тому же товару увеличивает количество в пределах остатка.

### Новые кейсы по штрихкоду и нагрузке

- [ ] Поиск по точному штрихкоду находит товар и выводит его первым.
- [ ] Сканер: одно точное совпадение — товар автоматически добавляется в корзину.
- [ ] Сканер: 0 совпадений — показывается понятная ошибка.
- [ ] Сканер: несколько совпадений — показывается подсказка выбрать вручную.
- [ ] Поиск по названию бренда с большим числом SKU не вызывает лагов/фризов на Android.
